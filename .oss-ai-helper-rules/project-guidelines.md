# Project Guidelines

Contribution settings for OSS Helper. Follow AGENTS.md.

- Fix branch naming pattern: ci-issue-<ISSUE_NUMBER>
- Feature branch naming pattern: ci-issue-<ISSUE_NUMBER>
- Bugfix branch naming pattern: ci-issue-<ISSUE_NUMBER>
- Quick-fix branch naming pattern: ci-issue-<ISSUE_NUMBER>
- SonarCloud branch naming pattern: none
- CI-fix branch naming pattern: ci-issue-<ISSUE_NUMBER>
- Commit format (fix): Fix #<ISSUE_NUMBER>: <brief description>
- Commit format (quick-fix): chore: <brief description>
- Commit format (ci-fix): ci: <brief description>
- Commit signing: prefer GPG signing; unsigned fallback is permitted
- PR creation policy: on request
- Find-task source: GitHub labels
- Find-task beginner label: good first issue
- Find-task intermediate label: none
- Find-task experienced label: help wanted
- Scope-too-large redirect: split work into focused issues
